# UROVO 竞品对比中心 · 清透版

## 离线预览
双击交付的“UROVO竞品对比中心_清透版_离线预览.html”，建议使用 Chrome 或 Edge。产品图片、品牌 Logo、数据和解析库均已内嵌，无需联网。品牌官网链接需要网络。

## 自行部署
解压部署包，将 index.html 及其同级文件和 assets、vendor 文件夹一起放在 GitHub 仓库根目录。Pages 选择 main / root。此目录通过 HTTP 服务运行；直接双击这个目录里的 index.html 会受到浏览器模块读取限制，请使用专门的离线预览文件。
